# 28 个 P 模板完整数据

> 来源：农机行业经销商拍摄库 V2.0
> 用于对标匹配时的数据底座，请勿修改字段名。

每个模板包含以下字段：
- p：作品编号（如 P01-01）
- type：作品类型
- benchmark：对标来源（抖音可搜）
- title：标题模板
- s：环境场景（S01-S06）
- v：车辆状态（V01-V05）
- h：人物出镜（H01-H06）
- m：农机出镜（M01-M06）
- duration：时长（秒）
- storyboard：拍摄顺序分镜
- note：一句话拍法 / 万古同悲层级 / 旁白文案
- painLevel：痛点等级（1-7，家国苍生=1 ... 男女情爱=7）
- heat：热度参考（高/中/低，基于对标账号粉丝量和历史数据）
