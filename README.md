# nongji-benchmark-matcher

农机经销商对标内容匹配器。用户提供当前环境条件（在哪）、人手（几个人、谁出镜）、车辆情况（什么车、什么状态）、拍摄设备（手机/无人机/稳定器），匹配抖音高评论高流量的可对标拍摄内容，搜索对标视频直链，以卡片式输出完整拍摄方案（含 BGM 推荐与评论区选题灵感）。

适用于每天拍摄前的选题决策。

**作者**：Dae.

**所有内容开放，可以整套装，也可以只拿一部分。模板库、BGM 库、对标账号库，都能单独用。**

## 核心能力

| 能力 | 说明 |
|---|---|
| 条件匹配 | 只推荐用户当前条件能拍的内容，不推荐超出条件的（如在展厅不推田间作业） |
| 实时对标数据 | 所有对标视频的点赞/评论/收藏/分享来自实时抓取，不编造数据 |
| 直链可点开 | 对标视频链接为抖音视频直链，可直接点开，不使用搜索结果页链接 |
| BGM 推荐 | 每张卡片匹配一首 BGM，标注歌曲名、艺人、截取时段（钩子段+高潮段）、适用理由 |
| 评论区选题灵感 | 从本轮找到的对标视频评论区提取用户关心的问题，生成可拍的选题角度 |
| 痛点等级合规 | 优先推荐家国苍生、社会冷暖等级的内容，满足每周占比要求 |
| 敏感词规避 | 自动将「国六」替换为「新款/最新款」、「DPF」替换为「后处理」、「尿素结晶」替换为「尾气处理」 |
| 设备适配 | 根据用户持有的设备调整拍摄手法推荐，仅有手机时不推航拍大场面 |
| 去编号化 | 输出给用户的内容全部用中文描述，不出现任何内部编号 |
| 无主观评分 | 不输出星级评分、推荐指数等主观评价，由用户自行判断 |
| 如实反馈 | 找不到对标视频时如实说明，不编造数据，并提供方向性建议 |

## 输入要求

用户需要提供以下信息，至少提供环境和车辆状态：

| 输入项 | 示例 | 是否必填 |
|---|---|---|
| 环境/地点 | 在展厅大院 / 在维修车间 / 在田里 / 在农户家 / 在路上 / 在配件仓库 | 必填 |
| 车辆情况 | 有一台车静止 / 有一台车在修 / 有客户的车在干活 | 必填 |
| 人手 | 我一个人 / 我+销售 / 我+售后师傅 / 有客户在场 | 选填 |
| 设备 | 只有手机 / 手机+无人机 / 手机+稳定器 / 手机+运动相机 | 选填 |
| 车型 | 麦赛福格森8700 / 2104 / 履带收割机 | 选填 |
| 地域 | 黑龙江佳木斯 / 河南驻马店 | 选填 |
| 特殊条件 | 有孤寡老人公益单 / 有跨区机手 / 今天有交车 | 选填 |

### 最少提问条件

如果用户只说"今天拍什么"没给任何条件，会问一句："你现在在哪、有什么车、车什么状态？手头有什么拍摄设备（手机/无人机/稳定器）？"

如果用户提供了环境+车辆状态，直接开始匹配，不再追问。设备未提供时默认按仅手机处理。

## 工作流

### 主线

```
解析用户条件（环境/车辆/人手/设备）
 ↓
匹配模板（环境+车辆+人物 三层匹配）
 ↓
排序（痛点等级 > 实时互动数据 > 条件匹配度 > 拍摄难度）
 ↓
搜索对标视频直链 + 抓取评论区
 ↓
卡片式输出（3-7 条，含 BGM 与选题灵感）
```

### 实时数据抓取

根据运行环境选择不同方式：

- **豆包环境**：直接调用豆包内置的抖音搜索能力，无需打开浏览器
- **非豆包环境**（如 Claude Code、Trae）：使用内置浏览器打开抖音搜索页，拦截搜索 API 响应获取数据

抓取的字段包括：视频标题、作者、点赞、评论、收藏、分享、视频直链。

评论区抓取同样根据环境选择方式，提取用户关心的问题用于生成选题灵感。

## 输出结构

每条匹配结果用一个卡片输出，包含：

| 板块 | 内容 |
|---|---|
| 对标视频 | 可直接点开的视频标题 + 直链 |
| 对标账号 | 账号名称 |
| 实时互动 | 点赞 / 评论 / 收藏 / 分享（数据来源标注） |
| 标题直接抄 | 替换好车型/地域的标题模板 |
| 维度小表格 | 环境 / 车辆 / 人物 / 农机 / 时长 |
| 拍摄顺序 | 分镜有序列表，纯中文描述 |
| 一句话拍法 | 关键拍摄提醒 |
| 推荐BGM | 歌曲名、艺人、截取时段、适用理由 |
| 评论区选题灵感 | 用户关心的问题 / 博主回答 / 换角度选题（3条） |

### 痛点等级参考

家国苍生 > 社会冷暖 > 生死离别 > 人生失意 ≈ 壮志豪情 > 父母子女 ≈ 男女情爱

每周家国苍生+社会冷暖占比建议不低于 40%。

### 怎么在你自己的项目里用

**场景 1：只拿模板**

直接读 `templates-28.md`，28 套拍摄模板自带标题、分镜、拍法，可以直接用于拍摄。

**场景 2：做对标账号库**

读 `benchmark-accounts.md`，里面是已验证的农机及跨行业对标账号。

**场景 3：做 BGM 匹配**

读 `bgm-library.md`，模板与 BGM 的对应关系已经做好，拿来就能用。

**场景 4：做选题灵感库**

读 `comment-ideas.md`，从评论区提炼的用户真实问题和选题角度。

## 使用示例

输入条件：门店展厅大院 + 一台车静止 + 我一个人 + 只有手机 + 今天有交车

输出 3-7 条卡片，按流量潜力排序。第一条可能是交车仪式（带红绸、揭绸、合影），第二条可能是问答答疑（站车旁边口播），第三条可能是静态展示（车的细节特写）。

每条都含可点开的对标直链、实时互动数据、BGM 推荐和 3 条评论区选题灵感。

## 安全与边界

- 不编造抖音账号，所有对标来源必须来自 references 中的已验证账号
- 不输出超出用户条件的模板（环境+车辆状态不符的不推）
- 敏感词自动替换，不直接输出「国六」「DPF」「尿素结晶」
- 不替代用户做最终拍摄决策，只提供匹配方案
- 互动数据为抓取时的实时快照，可能随时间变化，标注数据来源
- BGM 推荐来自参考库，商用需注意版权，蓝V号建议使用正版商用音乐
- 设备为软条件，仅优化农机出镜形式推荐，不做硬性排除
- 内部编号仅用于匹配逻辑，严禁出现在输出给用户的内容中
